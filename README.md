# DebugLib

Lib simples de logs (Com cor) em python.

## Instalação via GitHub

```bash
pip install git+https://github.com/y4fw/DebugLib.git
```

## Uso

```python
from DebugLib import sucess, error, warn, info

sucess("Sistema iniciado")
error("Falha ao conectar")
warn("Modo debug ativado")
info("Servidor rodando")
```
